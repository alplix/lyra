| [LYR-001] | high | boinc-lifecycle | CPU app: the search runs in threads of its own, which suspend, CPU throttling and preemption do not stop on Windows and Android | Start the CPU app with boinc_init_parallel() before any thread exists, or let the search threads wait while boinc_status.suspended is set (checked once per k) [PAT-025] |
| [LYR-002] | med | determinism | GPU app: the Fermat kernel is exact only below 2^95, so from k = 5338293918674499 its output differs from the CPU app's, and nothing checks the range | Refuse k1 >= 2^95 / 37# (5338293918674499) at start-up in symm27_gpu.c with a clear message, and give the limit to the work generator; or widen the kernel to 128 bits |
| [LYR-005] | med | device-selection | GPU app: the device comes only from --device; gpu_opencl_dev_index in init_data is never read | Read gpu_opencl_dev_index from init_data (boinc_get_init_data) and use it when >= 0, on the list BOINC counts (LYR-006); keep --device only for standalone runs [PAT-011] |
| [LYR-003] | low | io | Write errors on out are not checked before the checkpoint is removed and boinc_finish(0) is called | In both apps check fprintf/ferror and fclose on out; on failure keep the checkpoint and end without boinc_finish(0); remove the checkpoint only after a good close [PAT-006] |
| [LYR-004] | low | checkpoint | Checkpoint writes, close and rename are not checked, rename() is used instead of boinc_rename(), and the checkpoint is reported even when it was not written | Make save_ckpt() check every write and the fclose, use boinc_rename() under USE_BOINC and return success; call boinc_checkpoint_completed() only on success, boinc_end_critical_section() otherwise [PAT-003] |
| [LYR-006] | low | device-selection | GPU app: the GPUs of every platform that passes the vendor filter are put in one list, while BOINC's index counts within one platform | Choose one platform (the one whose vendor matches gpu_type) and index its CL_DEVICE_TYPE_GPU devices, as boinc_get_opencl_ids() does [PAT-012] |
| [LYR-008] | low | gpu-runtime | GPU app: the local work size 64 is hard-coded and never checked against the device's or the kernel's limit | Read CL_KERNEL_WORK_GROUP_SIZE of each kernel (clGetKernelWorkGroupInfo is already loaded) and use the largest power of two <= min(64, limit); the kernels need no particular size [PAT-015] |
| [LYR-009] | low | build | Release builds need the maintainer's build container: fixed /root paths, two helper scripts missing, no script for the macOS, Android and Windows arm64 builds | Call build_boinc_target.sh by its name, add runtest.sh, make the /root paths overridable, script the macOS, Android and Windows arm64 builds, record the BOINC and compiler versions [PAT-021] |
